## 一、背景与目标

项目是「生字笔顺乐园」——纯静态单页 Web，面向小学 1–6 年级学生练汉字笔顺。
技术栈：原生 HTML + CSS + **ES5 风格 JavaScript（var + function，无箭头函数/let/const/模板字符串）**，
无构建步骤，数据是 `window.HZ_CURRICULUM` / `window.HZ_DICT` / `window.HZ_STROKES`。

先读这些再动手：`README.md`、`index.html`、`js/app.js`、`js/store.js`、`css/app.css`。
相关既有函数：`store.js:189 pickDailyChars`、`store.js:216` 的硬编码兜底、`app.js:895` 的字帖预载、
`app.js:285` 册次列表渲染（`semList`）。

**问题现状**：`pickDailyChars` 恒从第一册（1a）开始扫，攒够 260 个候选就停，不足时用
`cur['1a'] || cur['1b']` 硬编码补。结果是**所有用户打开应用，打卡推的字都是一年级上册那批**，
中高年级孩子被推错字。

## 二、功能 A：年级 / 册次设置（P0-2，最高优先级）

### A1. 存储
- 新增 `settings.currentSem`，**默认 `'1a'`**。
- 不要写迁移脚本：`store.js` 的 `load()` 已用 `fresh()` 逐字段补齐缺失字段，旧存档会自动拿到默认值。
- 提供 `setSetting('currentSem', id)`（若已有通用 `setSetting` 就复用，没有就按现有风格加一个）。

### A2. 入口（**不要做首次启动强制弹窗**，会增加摩擦）
- 首页显示当前册次，做成**可点击**的元素：`当前：一年级上册 ▾`。
- 点击后弹出 12 册的选择网格，选中即切换并关闭弹窗。
- 复用项目现有的弹窗样式与写法（先在 `index.html` / `css/app.css` 里找现有弹窗实现并沿用，
  例如成绩弹窗；**若确实没有可复用的，就沿用 `js/app.js` 里已有的任何模态实现，不要引入新依赖**）。
- 切换后：立即重渲染当前页；如果当前在打卡页，刷新生字列表。

### A3. 生效范围（三处都要改，别漏）
1. **`pickDailyChars(n)`**（`store.js:189`）：
   - 优先从**当前册**收集候选；当前册不够 n 个时，再用**当前册之前的册**补。
   - **删除/替换 `:216` 那段 `cur['1a'] || cur['1b']` 的硬编码兜底**，改为按当前册兜底。
   - 候选池按**字去重**：同一个字在多个册出现时只保留一次，**归属优先当前册**。
2. **首页字帖预载**（`app.js:895` 附近的 `SEM_ORDER.slice(0, 4)`）：
   改为预载「当前册 + 上一册」，不要再固定前四册。
3. **闯关页**（`app.js:802` 附近）：打开时默认定位到当前册（若已是当前册则保持不动）。

### A4. 边界
- 当前册是第一册（1a）时，「之前的册」为空，不要报错，退回原有行为。
- `SEM_ORDER` 里若某个册在 `HZ_CURRICULUM` 中不存在，跳过它，不抛异常。

## 三、功能 B：3–6 年级分组自定义命名（P1-3 短期）

3–6 年级的课名在数据里是「第 N 组」，家长希望能有意义的名字。

### B1. 存储
- 新增 `settings.customNames = {}`（对象）。
- key 格式：`sem-unit-lesson`，例如 `3a-0-1`（`3a` 册、第 0 单元、第 1 课，全部从 0 开始）。
- value：字符串（家长输入的名字）。

### B2. 显示优先级
所有显示课名的地方，统一用 `customName(key) || 原课名`。至少覆盖：
- 目录页的课列表
- 生字页的课标题
- 练字页顶部「出自」信息
- 字典页「出自」信息

### B3. 交互
- 在课名旁显示一个**小的编辑图标按钮**（仅在课列表里出现即可，不必每处都放）。
- 点击 → **行内编辑**（把文字换成输入框 + 确定/取消）。**不要用 `window.prompt()`**
  （部分内嵌浏览器/WebView 会禁用它，体验也差）。
- 允许清空自定义名（清空后恢复原课名）。
