# 生字笔顺乐园 · 小学语文写字小游戏

面向小学阶段（以统编版／人教版教材为准）的**汉字笔顺学习小游戏**：在平板或电脑上用手指／触控笔照着楷体笔锋写字，实时判断笔顺对错，写对得星星和金币，攒金币养宠物、每天打卡孵蛋。

- **纯静态、无构建**：一个 `index.html` 加若干 `js / css / data` 文件，没有打包器、没有依赖安装。
- **完全离线**：无网络请求、无第三方统计、无广告、无内购、不收集任何个人信息；学习进度只存在本机浏览器。
- **字帖真实**：带笔锋的楷体轮廓（起笔尖、收笔粗），不是等宽线条描出来的。

在线体验：<https://hanzi-strokes.app.workbuddy.host/>（iPad / iPhone 用 Safari「分享 → 添加到主屏幕」可当 App 用）

## 一、核心功能

| 页面 | 说明 |
|---|---|
| **首页** | 宠物状态、金币 / 星星；六个入口：打卡、按课文学习、查字典、闯关、宠物、家长须知 |
| **按课文学习** | 选册 → 选单元 → 选课 → 本课字表 → 点字进入练字（1–3 年级逐课；4–6 年级按册分组） |
| **练字页** | 米字格 + 楷体笔锋字帖；「描红」跟着写 /「自己写」独立写；笔顺自动演示（慢 / 正常 / 快，自动记住）、擦一笔、看提示、整课连写 |
| **查字典** | 拼音查字（可省略声调，如 `chun`、`ch`）与部首查字，结果可直接点进去练字 |
| **闯关模式** | 每一课一关，按册浏览，通关给星星（1–3 星），记录历史最好成绩 |
| **宠物养成** | 宠物蛋 → 打卡孵化 → 幼生期 / 成长期 / 进化期；用金币喂食推进进化 |
| **每日打卡** | 每天最多 5 分钟（倒计时），系统自动挑 5 个「还没写好」的字；推进孵蛋进度、累计连续天数 |
| **家长须知** | 安全说明、内容来源、导出学习记录、一键清除记录 |

**朗读发音（国语 / 粤语 / English）**：练字页「自动朗读」旁有发音三档，切到生字时按当前档位读一次。国语读普通话语音（`zh-CN`），粤语读 `zh-HK` / `yue`，English 档把大字位置换成「英文单词 + 国际音标」。三档各有独立语音对象，按 `lang` 精确匹配并显式排除，互不串用。多音字**先读词再读单字**（「长短——长」），并按本课组词选正确读音：`长短` cháng / `长大` zhǎng，`处理` chǔ / `处所` chù，`大地` dì / `慢慢地跑` de。

**反馈规则（儿童友好）**：写对 → 提示音 + 笔画亮起 + 进度圆点变绿；笔顺错 → 柔和提示音 + 红笔圈出这一笔 + 自动演示正确的一笔，不扣分；写歪 → 提示「再试一次」，不扣分也不清空已写对的笔画；每字 1–3 星，错误 ≥3 次或用了提示才降星。

## 二、技术栈

| 层 | 选型 |
|---|---|
| 页面 | 原生 HTML + CSS + ES5 兼容 JavaScript（无框架、无打包器，双击 `index.html` 就能跑） |
| 渲染 | SVG（字帖轮廓，缩放不失真）+ Canvas 2D（手写笔迹，书写流畅） |
| 存储 | `localStorage`（键名 `hzpb.v1`）：进度、金币、宠物、设置全在本机 |
| 离线 | Service Worker（`sw.js`） |
| 语音 | Web Speech API（用系统自带语音，不下载任何音频文件） |

**没有后端、没有数据库、没有账号体系**——这是刻意设计：孩子用不上，也就没有隐私风险。

## 三、快速开始

运行游戏只要有现代浏览器（Chrome / Edge 90+、Safari 14+、Firefox 90+），推荐平板 + 手写笔；**不需要** Node.js、Python、网络或服务器。

```bash
git clone <仓库地址>
cd <仓库目录>
```

**方式 1 · 直接打开（零依赖）**：双击 `index.html`（macOS 也可 `open index.html`）。`file://` 协议下所有功能都能用，仅 Service Worker 例外。

**方式 2 · 本地服务（推荐，离线缓存才生效）**：

```bash
python3 -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000/index.html
```

也可双击 `启动服务.command`。

**方式 3 · 装到平板主屏幕**：用 Safari（iPadOS/iOS）或 Chrome（Android）打开上面的地址 →「分享 → 添加到主屏幕」。之后从桌面图标进入，全屏无地址栏，且首次访问后离线可用。

## 四、使用说明

### 改一个字的组词

直接编辑 `data/dict.js`（纯 JS，结构一目了然）：

```js
"春": { p:["chūn"], r:"日", s:9,
        w:["春天","春风","春雨"],
        wm:{ "春天":"一年四季中的第一个季节", "春风":"春天的风" },
        en:"spring", ipa:"[ˈsprɪŋ]" }
```

### 加一课

编辑 `data/curriculum.js`：

```js
window.HZ_CURRICULUM = {
  "1a": { id:"1a", name:"一年级上册", units:[
    { name:"第一单元 识字", lessons:[
      { id:"1a-0-0", name:"识字2《金木水火土》", chars:["一","二","三","上"] }
    ]}
  ]}
}
```

新增的字如果不在 `data/strokes/` 里，需要补字形数据。

### 跑测试

```bash
npm i jsdom                        # 仅命令行校验需要
node .build/verify.js              # 65 项：课文 / 拼音 / 多音字 / 三种发音 / IPA / 组词释义
node .build/regress.js             # 38 项：导航 / 练字 / 判分 / 字典 / 闯关 / 宠物 / 打卡 / 存档
node .build/run-smoke.js           # 113 项：真实浏览器冒烟测试（自动起服务 + headless Chrome + CDP）
```

冒烟测试也可双击 `运行冒烟测试.command`；`smoke-test.html` 手动打开时**必须经 HTTP 访问**（`file://` 下浏览器把每个本地文件当独立源，测试无法启动）。三套互补：`verify` 查数据与发音、`regress` 查既有功能、`run-smoke` 查真实渲染与交互。**退出码 0 表示全部通过**，改了数据请务必跑 `verify` 与 `regress`。

### 发布

```bash
./同步到发布目录.command      # 把可发布文件复制进 dist/
```

`dist/` 是发布副本，内容由根目录同步而来，**不要直接编辑**。

## 五、项目结构

```
.
├── index.html              入口页面。所有界面以 section 形式写在这里，靠 hidden 属性切换，无路由库
├── css/app.css             全部样式（可爱风 + 亮色 + 平板优先）
├── js/
│   ├── hanzi.js            字形引擎：轮廓解析与缩放、笔顺重采样与动画、手写轨迹判定、笔迹绘制
│   ├── app.js              业务层：页面渲染与交互、闯关、宠物、打卡、字典检索、朗读调度
│   └── store.js            本地存档：localStorage 读写（键 hzpb.v1）
├── data/
│   ├── curriculum.js       window.HZ_CURRICULUM：12 册课程表（册 → 单元 → 课 → 生字数组）
│   ├── dict.js             window.HZ_DICT：生字字典，p 读音 / pw 词→音 / r 部首 / s 笔画数 / w 组词 / wm 释义 / en 英文 / ipa 音标
│   ├── strokes/            笔顺轮廓数据，按册拆成 12 个文件（1a.js … 6b.js），进入某册时才加载
│   └── LICENSE-NOTICE.txt  字形数据的上游许可证声明（Arphic Public License）
├── assets/                 宠物形象 PNG 与应用图标
├── manifest.webmanifest    PWA 清单：名称、图标、全屏显示
├── sw.js                   Service Worker：离线缓存。改了 data/ 必须升 VER，否则老设备会一直吃旧缓存
├── smoke-test.html         浏览器内自测页（渲染 / 布局 / 像素 / 交互）
├── 启动服务.command         双击启动本地静态服务
├── 运行冒烟测试.command     双击跑冒烟测试（自动起服务并打开浏览器）
├── 同步到发布目录.command   把可发布文件复制进 dist/
└── scripts/                自动化脚本：auto-sync.sh（提交 + 推送）、guard-secrets.sh（提交前敏感信息守卫）、watch-sync.sh（常驻监听）
```

> `dist/`（发布副本）与 `.build/`（开发期数据构建脚本，运行游戏不需要）均已在 `.gitignore` 中排除，仓库里不含上游原始数据与体积较大的中间产物。

## 六、开发约定

- **提交信息**：遵循 [Conventional Commits](https://www.conventionalcommits.org/) —— `feat` / `fix` / `docs` / `refactor` / `test` / `chore`。
- **自动同步**：`scripts/auto-sync.sh` 一次完成「暂存 → 安全校验 → 生成提交信息 → 提交 → 推送」，推送失败会分类给出可复制的处理命令；`scripts/watch-sync.sh` 常驻监听，文件落盘并静默数秒后自动触发，避免「文件刚写一半就提交」。
- **提交前安全校验**：`scripts/guard-secrets.sh` 已挂到 `pre-commit`，按文件名与正文双重扫描密钥、凭据、`.env`、日志与临时文件，命中即终止提交（确需绕过用 `git commit --no-verify`，不推荐）。
- **改 `data/` 或 `sw.js` 后必须升 `sw.js` 里的 `VER`**，否则老设备拿不到新数据。
- 不要提交密钥、`.env`、日志、临时文件。
- 改 `data/*.js` 请先备份：脚本写入前会断言「重新序列化与原文逐字节一致」。
- 报问题请附浏览器与版本、所在页面、复现步骤、控制台报错；数据类错误请注明是哪个字、哪一册哪一课。

## 八、儿童使用安全

- 完全离线：没有网络请求、没有第三方统计、没有广告与内购。
- 没有任何外部链接，不会跳转离开本应用。
- 学习记录只存在本机浏览器；家长可在「家长须知」里导出或一键清除。
- 每次使用建议 10–15 分钟；「每日打卡」本身限制在 5 分钟内。
- 写错不惩罚、不倒计时施压，只做提示与演示。

## 九、已知限制

- 4–6 年级按册分组（每组 12 字、命名「第 N 组」），不是逐课——公开资料只到「册」，欢迎补数据。
- 笔顺判定采用轨迹相似度，**明显错序会拦住，潦草但方向正确会放过**，这是为儿童手感刻意放宽的。
- 粤语与英语发音依赖系统安装了对应语音；没装时会提示去哪里下载，不会拿其他语音顶替。
- 语气助词（呀 / 呢 / 吗 / 吧）没有对应英文，英语档下自动退回用国语读汉字。
- iOS 上 `speechSynthesis` 必须在用户手势内首次触发，页面已做处理；个别浏览器可能仍需在页面里点一下才有声。
