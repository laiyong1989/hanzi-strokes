# 生字笔顺乐园 · 小学语文写字小游戏

面向小学阶段（以人教版／统编版教材为准）的**汉字笔顺学习小游戏**：在平板或电脑上用手指／触控笔照着楷体笔锋写字，实时判断笔顺对错，写对得星星和金币，攒金币养宠物、每天打卡孵蛋。

全部离线运行，无广告、无内购、不联网、不收集任何个人信息。

---

## 一、快速开始

### 方式 1：在线版（推荐 · 不用开电脑）

**https://hanzi-strokes.app.workbuddy.host/**

手机、平板、电脑都能直接打开，不需要开着家里的电脑，也不需要连同一个 Wi-Fi。

- **装到主屏幕当 App 用**：iPad/iPhone 用 Safari 打开 → 点「分享 → 添加到主屏幕」；安卓用 Chrome → 菜单「添加到主屏幕」。之后从桌面图标进，全屏无地址栏，横屏体验更好。
- **断网也能用**：首次打开后，页面与已看过的字帖会缓存到本机，之后即使没网、在车上或飞机上，照样能练字。
- 学习进度存在**每台设备自己的浏览器里**，不会上传，也不会在设备之间同步。

### 方式 2：本机离线（不开电脑、不联网）
把整个文件夹拷到平板上，用支持本地网页的浏览器打开其中的 `index.html` 即可，无需任何服务器。
适合完全不想联网的场景；缺点是需要手动拷文件，进度也只留在那台设备上。

### 方式 3：局域网（临时调试用）
1. 双击 `启动服务.command`，终端会显示两个网址。
2. 平板与电脑连**同一个 Wi-Fi**，在平板浏览器打开 **http://电脑IP:8000/index.html**。

> 建议在平板上**横屏**使用；手指或 Apple Pencil 都能写，支持防手掌误触。

## 二、功能地图

| 页面 | 说明 |
|---|---|
| **首页** | 显示宠物状态、金币/星星；六个入口：打卡、按课文学习、查字典、闯关、宠物、家长须知 |
| **按课文学习** | 选册 → 选单元 → 选课 → 本课字表 → 点字进入练字（1–2 年级逐课；3–6 年级按册分组） |
| **练字页** | 米字格 + 楷体笔锋字帖；「描红」跟着写 /「自己写」独立写；自动演示笔顺（**慢 / 正常 / 快**三档可调，自动记住上次选择）、擦一笔、看提示、整课连写 |
| **查字典** | 拼音查字（可省略声调，如 `chun`、`ch`）与部首查字，结果可直接点进去练字 |
| **闯关模式** | 每一课一关，按册浏览，通关给星星（1–3 星），记录历史最好成绩 |
| **宠物养成** | 宠物蛋 → 打卡孵化 → 幼生期 / 成长期 / 进化期；用金币喂食推进进化；三种原创宠物可切换 |
| **每日打卡** | 每天最多 5 分钟（倒计时），系统自动挑 5 个「还没写好」的字；打卡推进孵蛋进度、累计连续天数 |
| **家长须知** | 安全说明、内容来源、导出学习记录、一键清除记录 |

### 演示速度
练字页右上角有「演示速度：慢 / 正常 / 快」三档，点击即生效，并写入本机存档，下次打开仍是这一档。
慢档约 1.9 倍时长，快档约 0.55 倍；影响自动演示、手动点「看笔顺动画」、「看提示」的单笔演示，以及笔与笔之间的停顿。

### 朗读发音（国语 / 粤语 / 英语）
练字页「自动朗读」旁边有**发音三档**，切到生字时按当前档位读一次（同一个字同一种发音不会重复读）：

| 档位 | 读什么 | 界面上显示什么 |
|---|---|---|
| **国语**（默认） | 汉字，普通话语音（`zh-CN`）；多音字先读词再读字 | 生字下面显示拼音（多音字按组词选正确读音） |
| **粤语** | 汉字，粤语语音（`zh-HK` / `yue`）；多音字同样先读词 | 生字下面显示拼音 |
| **English** | **这个字的英文单词**（如 春 → spring、猫 → cat） | 大字位置改成「英文单词 + 国际音标」，拼音收进右侧信息区的「English」一行 |

### 多音字怎么读
字典里每个字记录「会用到的读音」（`p`）和「哪个词里读哪个音」（`pw`）。
练字页有组词，于是可以像老师那样判断：

- 「长」：`长短` 里读 **cháng**，`长大` 里读 **zhǎng**
- 「处」：`处理` 里读 **chǔ**，`处所` 里读 **chù**
- 「地」：`大地` 读 **dì**，`慢慢地跑` 读 **de**

大字位置显示的是**按本课组词判断出来的那个音**，后面小字标出是哪个词；信息区再写一句「××里读 ××」。
朗读时多音字会**先读词再读单字**（如「长短——长」），因为单字交给语音引擎容易读错，放在词里才准。

读音来源：教材《写字表》原页自带的注音（一上/一下）＋ 人工校对的 94 个多音字词音表。
教材个别标注与规范不一致时以规范为准（例如教材把「长（长大）」标成 cháng，这里按规范取 zhǎng）。

### 三种发音互不串用
国语 / 粤语 / 英语各有自己的语音对象，切换档位只换自己那一套，**不会出现「选了粤语却读国语」**。
系统里没装某个语音时会提示一次去哪里下载，但不会拿另一种语音顶替。

### 英文注音
英文单词后面紧跟**国际音标**（IPA），统一**美式**，放在方括号里：`spring [ˈsprɪŋ]`、`water [ˈwɔɾɚ]`。
音标由 CMU Pronouncing Dictionary 转换而来（`.build/gen_ipa.py`），课内 2477 个单词 **100% 有音标**。

- 发音选择写入本机存档，下次打开还是这一档；切换档位会立刻用新发音把当前字重读一遍。
- 英文单词取自 `data/dict.js` 的 `en` 字段（课内 2481 字覆盖 2477 个）。
  语气助词（呀 / 呢 / 吗 / 吧）没有对应英文，英语档下会自动**退回用国语读汉字**，不会读错。
- **系统里必须装了对应语音才有对应口音**。没装粤语/英语语音时会提示一次：
  iOS/macOS 在「设置 → 辅助功能 → 朗读内容 → 声音」里下载，Windows 在「设置 → 时间和语言 → 语音」里添加。
- 语音挑选按 `lang` 精确匹配，**不会把粤语当国语用**（早期版本取「语音列表里第一个中文语音」，
  而 macOS 的列表里 `zh-HK` 粤语常常排在 `zh-CN` 前面，听起来就成了粤语）。

### 写字反馈规则（儿童友好）
- 写对了：轻快提示音 + 该笔画在字帖上「亮」起来 + 进度圆点变绿。
- 笔顺错了：柔和提示音 + 用红笔圈出这一笔 + **自动演示正确的那一笔**（黄色高亮 + 起笔圆点），并给出提示语，不扣分。
- 写歪了/没写对：提示「再试一次」，同样不扣分、不清空已写对的笔画。
- 每字 1–3 星：错误 ≥3 次或用了提示则降星，金币奖励随之变化。

## 三、目录结构

```
index.html              入口页面（所有界面都在这里）
css/app.css             样式（可爱风 / 亮色 / 平板优先）
js/hanzi.js             楷体笔锋渲染、笔顺动画、手写判定引擎
js/app.js               各页面逻辑、闯关、宠物、打卡、字典检索
js/store.js             本地进度存储（localStorage）
data/curriculum.js      教材写字表课程数据（12 册 / 2483 字）
data/dict.js            生字字典（拼音 / 部首 / 笔画数 / 释义）
data/strokes/*.js       笔顺轮廓数据（按册拆分，按需加载）
assets/pets/*.png       宠物形象（11 张，AI 生成 + 抠白底，原创设计）
assets/icon-*.png       应用图标（在线版添加到主屏幕时用）
manifest.webmanifest    网页应用清单（名称、图标、全屏显示）
sw.js                   离线缓存：装到平板后断网也能练字
smoke-test.html         自动化测试页（浏览器打开即跑，共 110 项检查）
启动服务.command        macOS 一键启动本地服务（局域网给平板用）
dist/                   **发布到线上用的副本**（由下面的同步命令生成，不要直接改这里的文件）
.build/                 构建脚本、原始数据与排查用诊断页（运行游戏不需要）
```

### 改了代码之后怎么更新线上版
双击 `同步到发布目录.command`（把改动复制进 `dist/`），再让我发布一次即可。
线上链接不变，内容会被替换。

## 四、内容与数据来源

- **笔顺轮廓与笔顺中心线**：Make Me a Hanzi / hanzi-writer-data，字形来自 Arphic Public License 授权字体，
  因此书写演示是**真实的楷体轮廓，带笔锋（起笔尖、收笔粗）**，而不是把字描成等宽线条。
  许可证见 `data/LICENSE-NOTICE.txt`。
- **拼音、部首**：Make Me a Hanzi `dictionary.txt`（它每个字只给一个主读音，多音字因此不准，
  已用教材注音 + 人工词音表重做，见上文「多音字怎么读」）。
- **英文单词的国际音标**：CMU Pronouncing Dictionary（ARPABET 音素转成美式 IPA）。
- **笔画数**：由所用笔顺轮廓数据逐字统计，与演示动画完全一致。
- **组词**：从教材《写字表》配套资料中提取（要求词中必须含本字），并为三至六年级逐字补齐；
  现在 **课内 2481 个生字，每个都有 2~3 个常用组词**。
- **释义**：随包发布。每个组词都配一句适合低年级理解的短释义（共 5038 条），
  存在 `data/dict.js` 的 `wm` 字段（词 → 释义）里，生字页与练字页都会显示。
  课外字（只在字典页查到、不在课本里的字）仍只显示「拼音 / 部首 / 笔画数 / 组词 / 出自哪一课」。
- **课程结构**：依据统编版（部编版）小学语文教材《写字表》公开整理资料编排。

> 说明：一、二年级为**逐课**（课名与教材一致）；三至六年级因公开资料只到「册」，按册分组编排，
> 每组 12 字、命名为「第 N 组」。不同教材印次/版本可能有个别生字差异，可在下方自行调整。

## 五、如何修改或扩充教材数据

课程数据是纯 JavaScript，直接改 `data/curriculum.js` 即可（结构一目了然）：

```js
window.HZ_CURRICULUM = {
  "1a": { id:"1a", name:"一年级上册", units:[
    { name:"第一单元 识字", lessons:[
      { id:"1a-0-0", name:"识字2《金木水火土》", chars:["一","二","三","上"] }
    ]}
  ]}
}
```

新增的字如果不在 `data/strokes/` 里，需要重新生成笔顺数据：

```bash
cd .build
python3 build_data.py     # 会读取 hwd/（笔顺数据）与 word.json（字典）后重写 data/
```

## 六、自检与测试

浏览器打开 `smoke-test.html`，会自动跑 **99 项检查**并逐条列出结果，覆盖：

- 数据完整性（12 册、约 2500 字、每册课数、字典字段）
- 笔顺引擎（正确笔画被接受、**先写第二笔会被判为笔顺错误且不进进度**、写完后多余笔画不崩溃、乱画不通过、抖动不产生笔画）
- 触摸/手写链路（真实派发 pointer 事件，验证轨迹能被判定通过）
- 笔迹是否真的画到画布上（读取 canvas 像素计数）
- 各页面可渲染、可交互、按钮不报错、返回栈正确
- 配色与设计一致（主题蓝、米字格淡红线、楷体墨色、描红浅灰）
- 布局（4 种视口下**零横向溢出**、练字台正方形且不超出视口、按钮 ≥38px、首页功能块 ≥44px）
- **`hidden` 属性真的隐藏**（用 `getComputedStyle` 判定，而不是读 `hidden` 属性）
- **图标结构完整**（子元素数量正确，细节线段有描边色）
- 打卡领奖、金币同步、宠物图片真实解码、无 JS 报错

### 命令行自动校验（无需浏览器）

`smoke-test.html` 里的布局、像素、动画时长类检查必须靠真实浏览器。
如果只想快速确认「数据和交互没被改坏」，可以跑下面两个 Node 脚本（用 jsdom 模拟页面，不需要浏览器）：

```bash
NODE_PATH=<node_modules 路径> node .build/verify.js    # 48 项：课文/拼音/多音字/三种发音/IPA/组词释义
NODE_PATH=<node_modules 路径> node .build/regress.js   # 36 项：导航/练字/存档/各页面等既有功能
```

两者都以退出码 0 表示全部通过。脚本自带临时静态服务，不依赖外部进程。

## 七、儿童使用安全

- 完全离线：没有网络请求、没有第三方统计、没有广告与内购。
- 没有任何外部链接，不会跳转离开本应用。
- 学习记录只存在本机浏览器中；家长可在「家长须知」里导出或一键清除。
- 每次使用建议 10–15 分钟；「每日打卡」本身限制在 5 分钟内。
- 写错不惩罚、不倒计时施压，只做提示与演示。

## 八、已知限制

- 二三六年级（3–6 年级）按册分组，不是逐课（公开资料所限，可按第四节自行补全）。
- 笔顺判定采用轨迹相似度（位置/方向/长度），对手写体宽容度较高：**明显错序会拦住，潦草但方向正确会放过**，这是为儿童手感刻意放宽的。
- 字典目前没有逐字释义（有拼音、部首、笔画数、组词、出处）；按第五节可自行补入。
- 组词覆盖约 960 字（一、二年级为主），没有组词的字不会显示该行。
